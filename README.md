# Конспект лекций — установщики

Программа делает из аудиозаписи лекции расшифровку с таймкодами (лектор и слушатели отдельно)
и структурированный конспект в DOCX и Markdown.

Скачайте последнюю версию в разделе [Releases](https://github.com/alexbayd12/konspekt-releases/releases/latest):

- **Windows 10/11 (x64):** `Konspekt-Setup-<версия>-win-x64.exe` — установка без прав администратора.
  Если Windows предупредит о неизвестном издателе: «Подробнее» → «Выполнить в любом случае».
- **macOS (Apple Silicon):** `Konspekt-<версия>-mac-arm64.dmg` — перетащите приложение в «Программы».
  Первый запуск: правый щелчок по приложению → «Открыть» → «Открыть».

Установленная программа сама находит новые версии здесь: кнопка «Обновить и перезапустить» скачивает
и ставит обновление, лекции и настройки сохраняются.

В этом репозитории только установщики.
